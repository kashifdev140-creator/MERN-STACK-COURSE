CSS Guide: Block, Inline, Spacing & Units

1. Block vs Inline Elements

Block Element 1 (<div>)
Block Element 2 (<p>, <h1>)

Note: Block elements naye line se shuru hote hain aur poori width lete hain.

Yeh ek normal sentence hai jisme Inline 1 (<span>) aur Inline 2 (<a>) ek hi line mein sath chalte hain.

Note: Inline elements nayi line nahi banate aur sirf apna zaroorat jitna space lete hain.

2. Padding vs Margin

Is card mein Padding (20px) ne andar ke content ko border se door rakha hai, aur Margin (30px) ne do cards ke beech mein space banaya hai.

3. CSS Units (px, %, rem, vh)

300px Width: Fixed size (hamesha 300px rahega).
50% Width: Screen ke hisab se resize hota hai.

2rem Text: Base size (16px) * 2 = 32px.

15vh Height: Screen ki height ka 15% hissa.
